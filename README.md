# s3hq4y — World Builder

Personal site of **s3hq4y (s9y)** — built from imagination.

🌐 Live at: <https://s3hq4y.github.io>

## What this is

A single-page, dependency-free personal site with a dark strategy-game HUD
aesthetic:

- 🌌 Animated starfield (canvas) with parallax & shooting stars
- ⌨️ Typewriter tagline
- 🖥️ HUD status panel
- 🃏 Tilt + glow project cards
- 📜 Scroll-reveal animations
- ♿ Respects `prefers-reduced-motion`

No frameworks, no build step — just `index.html`, `style.css`, `script.js`.

## Local dev

```bash
python -m http.server 8080
# → http://localhost:8080
```
