Portal

一个 VS Code 扩展：把你的工作区变成公开的 MCP 端点。

portal — VS Code Extension
运行中 · 隧道已连接 MIT · TypeScript · VS Code ≥ 1.95.0

Portal 将当前 VS Code 工作区暴露为公开的 MCP 端点——刻意保持精简：只包含命令执行与文件传输。任何 MCP 客户端（Claude、ChatGPT、Cursor，甚至 curl）都能通过隧道连接到你的机器，执行 shell 并移动文件。

MCP over HTTP Streamable HTTP，端点 /mcp/<token>
文件 HTTP API 上传 · 下载 · 打包/解包 · 64 MiB · SHA-256
恰好五个工具 run · start · read · stop · 文件信息，没有更多
四种隧道方式 Cloudflare 快速/命名 · ngrok · 自定义命令
支持所有 Shell PowerShell · pwsh · cmd · Git Bash，自动 UTF-8
Fluent 风格侧边栏 启动/停止 · 复制 URL · 隧道健康状态
五个 MCP 工具
  • run_command 前台命令 —— 默认 120 秒超时，最长 600 秒
  • start_command 启动长时任务 —— 最多四个并行
  • read_command 按偏移量增量读取输出，环形缓冲区
  • stop_command 停止任务及其整个进程树
  • file_transfer_info 文件 API 地址、大小限制、curl 示例
在 GitHub 查看 README
